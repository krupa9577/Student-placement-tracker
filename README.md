# 🎓 Student Placement Tracker

A Python-based web application built with Streamlit to manage student records and track placement eligibility through a simple, user-friendly interface.

## 📌 Project Overview

The Student Placement Tracker helps organize student information and simplifies the process of checking placement eligibility based on predefined criteria.

## ✨ Features

- ➕ Add new student records
- 👀 View student details
- 🔍 Search students by USN
- ✏️ Edit existing student records
- 🗑️ Delete student records
- 📂 Import student datasets from CSV and Excel files
- ✅ Check placement eligibility based on CGPA and backlog criteria

## 🛠️ Technologies Used

- Python
- Streamlit
- Pandas
- CSV
- Excel

## ⚙️ Installation and Setup

### 1. Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Open the project folder

```bash
cd Student-Placement-Tracker
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Run the application

```bash
streamlit run app.py
```

Open the local URL displayed in your terminal to access the application.

## 🎯 Project Objective

To provide a simple system for managing student placement information, maintaining organized records, and identifying students who meet the configured placement eligibility requirements.
